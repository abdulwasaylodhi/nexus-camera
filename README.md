# nexus-camera
# Camera Path for SketchUp

Build smooth orbits, locked match cuts and A-to-B fly-throughs
as SketchUp scenes, ready to export as animation.

A SketchUp extension for building camera paths — smooth orbits, locked match cuts and A-to-B fly-throughs — generated as SketchUp scenes and ready to export as animation. Distributed as releases with a dedicated support channel.
